# Manual de Usuario

## 1. Introducción
Bienvenido a Chat Home IA, tu asistente inteligente para resolver problemas y dudas del hogar. Este manual te guiará paso a paso para que aprendas a registrarte y utilizar la aplicación sin complicaciones.

## 2. Registro e Inicio de Sesión
Para poder hablar con el asistente, lo primero que necesitas es una cuenta.

**Pasos para registrarte:**
1. Abre la aplicación en tu navegador. Lo primero que verás será la pantalla de inicio de sesión.
2. Como aún no tienes cuenta, haz clic en el enlace que dice "¿Eres nuevo? Crea una cuenta" en la parte inferior del formulario.
3. Rellena el formulario con tu nombre de usuario, correo electrónico y una contraseña segura.
4. Pulsa el botón de registrar. Si todo va bien, el sistema te redirigirá automáticamente dentro de la aplicación.

![Registro usuario](imgs/registro.png)

**Pasos para iniciar sesión:**
1. Abre la aplicación en tu navegador. Lo primero que verás será la pantalla de inicio de sesión.
2. Como ya tienes cuenta rellena el formulario de inicio de sesión con tu correo electrónico y contraseña.
3. Pulsa el botón de iniciar sesión. Si todo va bien, el sistema te redirigirá automáticamente dentro de la aplicación.

![Login usuario](imgs/login.png)

## 3. Cómo interactuar con el Chat
Una vez dentro, entrarás directamente a la pantalla principal del chat.

**Cómo usarlo:**
1. En la parte inferior de la pantalla verás una barra de texto. Escribe ahí tu consulta (por ejemplo: "¿Cómo quito una mancha de vino de la alfombra?").
2. Pulsa la tecla **Enter** o haz clic en el botón de enviar (el icono del avión de papel).
3. Espera unos segundos. La IA procesará tu petición y te responderá con la solución detallada en la pantalla.
4. Puedes seguir preguntando sobre el mismo tema o cambiar de asunto con total libertad.

![Consulta a la IA](imgs/consulta.png)

## 4. Solución de Problemas
A veces las cosas fallan, es normal. Aquí tienes las soluciones a los problemas más comunes:

* **Problema:** Pongo mi usuario y contraseña pero no me deja entrar.
    * **Solución:** Comprueba que no tengas las mayúsculas activadas. Si te acabas de registrar, asegúrate de que estás usando exactamente el mismo correo.
* **Problema:** Envío un mensaje por el chat pero se queda pensando y no responde.
    * **Solución:** Esto suele pasar si hay un corte en tu conexión a internet o si el servidor de la IA está saturado. Refresca la página (F5) y vuelve a enviar el mensaje. 

## 5. Preguntas Frecuentes

**¿Es gratis usar Chat Home?**
Sí, el uso de la aplicación es totalmente gratuito para los usuarios registrados.

**¿Qué pasa con mis datos y las conversaciones?**
Tus datos de inicio de sesión están encriptados y protegidos. Las conversaciones se procesan para darte una respuesta, pero te recomendamos no compartir información personal sensible con la IA.

**¿Qué tipo de preguntas puedo hacerle al chat?**
Está especializado en el hogar. Puedes preguntarle sobre bricolaje, limpieza, reparaciones básicas, cocina o incluso organización de tareas domésticas.
